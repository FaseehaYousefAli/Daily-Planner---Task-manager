# Daily Planner

A clean, distraction-free daily task planner designed with a soothing botanical palette and layered card contrast. Built entirely in vanilla HTML, CSS, and JavaScript with zero external dependencies.

### ✨ Features
- **Weekly Calendar Strip:** Quickly navigate days, jump across weeks, or pick any specific date.
- **Color-Coded Categories:** Organize tasks across *Work*, *Personal*, and *Appointments* with distinct visual accents.
- **Daily Progress Tracker:** Real-time completion bar and percentage breakdown for the selected day.
- **Priority Levels & Notes:** Tag tasks as *High*, *Medium*, or *Low* priority with optional descriptions.
- **Completed Archive:** Dedicated view for finished tasks grouped by category.
- **Light & Dark Mode:** One-click theme toggle that remembers your preference.
- **Offline Persistence:** Saves all tasks and settings directly in the browser via `localStorage`.
